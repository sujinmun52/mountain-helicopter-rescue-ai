# 산악구조 최적화 AI 시스템 — 발표 정리 (PPT 기반자료) v2

작성일: 2026-06-09 | 발표: 6/11
평가기준: **완성도(1/3) · 난이도(1/3) · 통찰(1/3)** + 상호평가 50%

---

## ★ 핵심 메시지 (한 문장)

> **"설악산은 안전 착륙지가 전체의 3.5%뿐인 험준지형. 사람이 육안으로 못 찾는 이 희소한 안전지를, 기종·실시간 기상까지 반영해 ML이 정밀 탐색하고, A*가 위험을 피해 안전하게 도달한다."**

- **핵심 가치**: 희소 안전지 정밀탐색 (안전 + 속도)
- **ML의 위치**: 시스템의 **가장 중요한 결정**("어디 내릴까")을 담당 — 곁다리 아님
- **A*의 위치**: 그 결정을 안전하게 **실행**(보행=지형, 비행=풍속)

## 슬라이드 1 — 표지
- 산악구조 최적화 AI 시스템 / 팀·발표자·날짜

## 슬라이드 2 — 문제: 왜 필요한가  `[통찰]`
- 산악 조난 구조의 **두 가지 난제**:
  1. **어디 내릴까** — 잘못 내리면 2차 사고. 그런데 **설악산 안전 착륙지는 3.5%뿐**
  2. **어떻게 갈까** — 골든타임. 험준지형에서 빠르고 안전한 접근
- **사람의 한계**: 험준한 산에서 안전지를 육안·지도로 즉시 판단 불가
- → **데이터·AI로 희소 안전지를 정밀 탐색하는 의사결정 지원이 필요**

## 슬라이드 3 — 시스템 개요  `[완성도]`
- 입력: 조난자 GPS + 지형(DEM·임상도) + 실시간 기상(KMA AWS)
- **ML(의사결정)**: 149만 후보 격자를 실시간 평가 → 최적 안전 착륙지·전술 선정
- **A*(실행)**: 보행=지형 회피, 비행=풍속 회피로 안전 경로
- 출력: 착륙지 + 경로 + ETA + 미션 지도
- Stage 1→4 end-to-end (`python main.py`)

## 슬라이드 4 — 데이터  `[완성도]`
- 지형: 설악산 15m DEM + 임상도(수관밀도·수고) → 149만 격자
- 기상: KMA AWS 5개소, 고도보정(멱법칙 α=0.27)
- 피처 10개 / 타겟 3등급(안전·주의·위험)

## 슬라이드 5 — ★ ML: 핵심 의사결정 (착륙지 선정)  `[난이도]`
- **XGBoost 4모드**: small/large × landing/hoist (기종·전술별)
- **149만 후보 → 실시간 위험 평가 → 안전지 선정** (사람이 못 하는 규모·속도)
- **모드별 가중치가 도메인 물리 반영**:
  - landing → **경사** 중심 (slope 0.46)
  - hoist → **임목밀도·수고** 중심 (density 0.24)
- 정적(지형) + 동적(실시간 풍속·풍향) 융합 Risk Score

## 슬라이드 6 — ML 검증 (성능지표)  `[완성도]`
- test셋 848만 행

| 모드 | Accuracy | F1(macro) |
|------|----------|-----------|
| small_landing | 0.951 | 0.910 |
| large_landing | **0.991** | 0.955 |
| large_hoist | 0.950 | 0.932 |

- Confusion Matrix: **위험을 안전으로 오분류 = 0건** (안전성)

## 슬라이드 7 — ★ 인사이트 ①: 안전지 희소성  `[통찰]`
- 설악산 격자 위험분포 (풍속 6.5m/s 기준):

| 모드 | 안전 | 주의 | 위험 |
|------|------|------|------|
| small_landing | 10.2% | 34.9% | 55.0% |
| large_hoist | 4.4% | 24.4% | **71.3%** |

- **안전 착륙지 3.5~10%** → "사람이 못 찾으니 AI가 필요"의 직접 근거
- → 희소성 자체가 **프로젝트의 존재 이유**

## 슬라이드 8 — ★ 인사이트 ②: 기종·전술별 위험 차이  `[통찰]` `[난이도]`
- **large_hoist가 가장 보수적(위험 71%)인 이유 분석**:
  - 호이스트는 임목밀도·수고 가중 → 설악산 **72.6%가 수관밀도 70%+(밀)**
  - 근거(산림청 임상도): 소(≤50%)/중(51~70%)/밀(70%+)
  - 70%+ 울폐림은 직접 호이스트 불가 → 환자 이송 후 인양 = **운용 현실 일치**
- → 모델이 **실제 산악구조 물리 제약을 정확히 반영** (단순 분류 아님)

## 슬라이드 9 — ★ 인사이트 ③: 동적 기상 반영 (풍속 무반응 → 해결)  `[통찰]` `[난이도]`
**문제 발견 → 피처 엔지니어링으로 해결한 과정**
- **Before**: 초기 모델은 풍속을 0→25 바꿔도 예측 동일 (무반응)
  - 원인: 학습 데이터가 약풍(0~4.9 m/s)에 치우쳐 풍속을 변별 못 배움
- **해결**: 물리변수 **비선형 상호작용 피처** 추가 (룰 점수 배제, 치팅 방지)
  - `aero_risk` = 고도×풍속, `slope_wind_risk` = 경사×풍속
- **After**: 풍속 ↑ → 위험도 ↑ (2m/s 67% → 16m/s 82%)

| 풍속 | 위험(2) 비율 |
|------|--------------|
| 2 m/s | 67% |
| 8 m/s | 68% |
| 16 m/s | **82%** ↑ |

- 고도보정(멱법칙 α=0.27): 지상 풍속 → 헬기 운용고도 환산 (저지대 잔잔해도 고지대 강풍)
- 기종별 운용 풍속 제한(소형10/대형20, 항공안전법 별표24) 반영
- → 교훈: **"학습 데이터 분포·피처 설계가 모델의 기상 반영을 결정"**

## 슬라이드 10 — A*: 안전 경로 실행  `[난이도]`
- **보행 A***: Tobler 보행시간(경사) + 임상저항 → 위험지형 회피하며 빠르게
- **비행 A***: 풍속·풍향·능선난류 회피 (순항고도 직선 기반 + 위험구간 우회)
  - 근거: 산악구조는 이동=순항직선(최속), 산악접근=지형·바람 회피(안전) (EASA/SAR)
- 결과 예시: 비행 6.3분 + 도보 5.4분 = **총 11.6분**

## 슬라이드 11 — ★ 메인 결과: A*가 구조시간을 줄인다  `[완성도]` `[통찰]`
**"최단거리 ≠ 최단시간" — 직선 vs A* 비교 (험준 구간)**

| 지표 | 단순 직선 | A* 안전경로 | 개선 |
|------|-----------|-------------|------|
| 거리 | 짧음 | +33% (우회) | — |
| 평균 경사 | 30.5° | **15.5°** | **경사 ½** |
| 최대 경사 | 37.7° | 27.2° | 완화 |
| 도보 소요시간 | 기준 | — | **약 58% ↓** |

- 직선은 짧아 보여도 **급경사를 무리하게 통과 → 보행 위험·비효율**
- A*는 거리를 +33% 우회하지만 **완경사를 선택 → 경사 절반, 시간 약 58% 단축**
- → **거리를 감수하고 "안전하게 구조시간을 줄인다"를 정량 증명**
- ⚠️ *절대 분(min)은 현재 격자 해상도(셀 81~140m)에서 보수적 추정 →
  비율(경사·시간 개선)이 핵심 지표. 15m DEM 적용 시 절대값 정밀화 가능(향후)*

## 슬라이드 12 — 결과 (E2E 데모)  `[완성도]`

- Stage 2: large_landing, 안전등급 0, RiskScore 0.87 / Stage 3: 총 11.6분

## 슬라이드 13 — 개발 과정의 발견 (디버깅 통찰)  `[통찰]`
1. **경사도 버그**: 격자 셀(81~140m)을 15m로 계산 → 경사 폭증 → 보행불가
   - 수정: 실제 셀 간격 반영 → 경사 73°→24°, 구조 ETA **66분→12분**
   - 교훈: "격자 해상도와 물리 계산의 정합성이 결과를 좌우"
2. **외부 검증 시도**: 국립공원 위험지역으로 검증 → 변별력 한계 발견
   - 설악산 전역이 위험으로 분류돼 변별 어려움 + "고립위험 ≠ 착륙위험"
   - 교훈: "외부 검증의 어려움 + 개념 정의의 중요성"

## 슬라이드 14 — ML의 정직한 위치 & 한계  `[통찰]`
- **현 ML = 룰 대리모델(surrogate)** — 실측 사고데이터가 없어 도메인 룰로 정답 정의
- **가치**: 149만 후보 고속·일관 평가, 일반화, 검증 가능
- **한계**: 룰을 못 넘음 → **실측 라벨 확보 시 진짜 지도학습으로 고도화**
- **풍속 반응**: ✅ 해결 — 물리변수 상호작용 피처로 무반응 극복 (슬라이드 9)
- **격자 해상도**: 현재 200격자(셀 81~140m) → **15m DEM 원본 활용 시 경로·시간 정밀화** (향후)

## 슬라이드 15 — 결론  `[통찰]`
- 설악산 안전 착륙지 3.5% → **육안으로 못 찾는 안전지를 ML로 정밀 탐색**
- **ML = 핵심 의사결정(착륙지), A* = 안전 실행(경로)** 역할 분담
- 도메인 분석(기종별 위험·임상밀도)으로 **현실 부합성** 확인
- 한계(surrogate·데이터)를 데이터로 진단 → **"문제를 제대로 이해한 시스템"**
